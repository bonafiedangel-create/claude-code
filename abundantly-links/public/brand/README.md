Unzip "Abundantly Olive Crest - OFFICIAL logo pack (SVG + PNG + ready-to-use).zip"
(Google Drive › AbundantlyMari Brand Identity › OFFICIAL - Olive Crest) and copy these
files into this folder, renamed exactly like this:

| File name here                      | Which file from the pack                         |
| ----------------------------------- | ------------------------------------------------ |
| olive-crest-horizontal.svg          | horizontal lockup, ink/terracotta (for daylight) |
| olive-crest-horizontal-ivory.svg    | horizontal lockup, reversed ivory (for night)    |
| favicon.svg / favicon.ico           | favicon from the pack                            |
| apple-touch-icon.png                | 180x180 icon from the pack                       |
| share-card.jpg                      | "LIVE - Homepage share card 1200x630.jpg"        |

The site picks them up automatically on the next build. Until then it shows the text
wordmark "ABUNDANTLY by Mari" (plain type, not a redrawn logo).
